# FileOrganizer 0.1.0-beta.1

This is the first public Windows x64 portable beta.

## What is included

- A versioned JSON configuration editor.
- Watched-root monitoring with explicit synchronization and rescan states.
- Stable-file observation and immutable read-only organization previews.
- A self-contained Windows x64 directory package; a separate .NET runtime is
  not required.

## Important limitations

- The desktop UI does not execute organization plans or organization actions
  against watched candidates. The explicitly selected configuration document
  remains writable even if its path is inside a watched root.
- This beta has no installer or automatic updater.
- The executable is not Authenticode-signed, so Windows SmartScreen or publisher
  warnings may appear.
- Interactive visual layout and workflow verification is **Not Tested** for this
  release candidate; treat the desktop surface as beta quality.

See the [safety model](https://github.com/seneshakki/FileOrganizer/blob/v0.1.0-beta.1/docs/safety-model.md)
for the exact trust boundaries.

## Download and verify

Download both release files:

- `FileOrganizer-0.1.0-beta.1-win-x64-portable.zip`
- `FileOrganizer-0.1.0-beta.1-win-x64-portable.zip.sha256`

Verify the archive in PowerShell:

```powershell
$expected = (Get-Content .\FileOrganizer-0.1.0-beta.1-win-x64-portable.zip.sha256).Split()[0]
$actual = (Get-FileHash .\FileOrganizer-0.1.0-beta.1-win-x64-portable.zip -Algorithm SHA256).Hash
$actual -eq $expected
```

Extract the ZIP to a new folder and run `FileOrganizer.App.exe`.
